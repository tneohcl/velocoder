**See and adjust the exact numbers behind Normal's plain-language choices.**

Expert exposes the exact technical values behind Normal's plain-language choices -- the same settings, just with the real numbers instead of Smaller File/Balanced/Better Quality. Nothing here is required reading; Normal's defaults already produce a sensible result.

![The expanded Expert section, showing Rate Control, Exact Quality, Encoding Speed, and Force Deinterlace](expert-settings.png)

Expert is entirely optional and only affects the currently selected encoding path -- it never changes what Normal's own buttons mean.

> **Note**
> Expert's own defaults already match Normal's -- opening it doesn't change anything until you do.
