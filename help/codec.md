**H.265 (HEVC)** creates smaller files at similar visual quality. Choose it for newer devices and efficient storage.

**H.264 (AVC)** works with a wider range of devices and software, at a larger file size for the same quality. Choose it when playback compatibility matters most -- older TVs, some browsers, and some editing software still don't handle H.265 well.

Codec only applies when Processing is set to CPU -- Intel and AMD hardware encoding here always produces H.265.
