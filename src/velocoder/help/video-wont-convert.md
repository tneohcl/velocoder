A row showing **Failed** means that video's conversion hit a real error -- the reason is shown in red under the file name (hover the row for the full text, or check the Conversion Log). Common causes: the source file is corrupted or in a format VeloCoder can't read, or there isn't enough free space in the Save-to folder.

Fixing the underlying issue and pressing **Convert** again will retry it along with anything else still unfinished in the queue. Videos that already converted are never redone; once every video is done, Convert stays off until you add more.
